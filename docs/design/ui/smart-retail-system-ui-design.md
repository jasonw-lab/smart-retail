> **対象範囲**: システム管理機能の画面設計

---

## 1. 画面一覧

| 画面ID | 画面名 | 主要機能 | 優先度 |
|--------|--------|---------|--------|
| SYS-01 | ユーザー管理 | ユーザーマスタ管理、インポート/エクスポート | **必須** |
| SYS-02 | ロール管理 | ロール定義、権限割当 | **必須** |

| SYS-06 | 操作ログ | 操作履歴閲覧 | 任意 |

| SYS-08 | 通知管理 | お知らせ配信管理 | 任意 |
| AUTH-01 | ログイン | 認証・ログイン | **必須** |
| USR-01 | プロファイル | 個人情報・セキュリティ設定 | **必須** |

### 2.3 UI コンポーネント詳細

#### 2.3.1 部門ツリー（左パネル）

| 項目 | 説明 |
|------|------|
| 表示形式 | ツリー構造（折りたたみ可） |

| 項目 | タイプ | 説明 |

| メール | 160px | メールアドレス | - |
| ステータス | 80px | 有効/無効 | ✓ |
| 作成日時 | 150px | 登録日時 | ✓ |
| 操作 | 220px | PW再設定/編集/削除 | - |

## 12. 共通仕様

### 12.1 権限制御

各画面・操作には権限識別子（パーミッション）が設定されており、ロールに割り当てられた権限に基づいてUI要素の表示/非表示が制御される。

| 画面 | 権限識別子例 |
|-----|-------------|
| ユーザー管理 | `sys:user:add`, `sys:user:edit`, `sys:user:delete`, `sys:user:import`, `sys:user:export` |
| ロール管理 | `sys:role:add`, `sys:role:edit`, `sys:role:delete` |
| 部門管理 | `sys:dept:add`, `sys:dept:edit`, `sys:dept:delete` |
| メニュー管理 | `sys:menu:add`, `sys:menu:edit`, `sys:menu:delete` |
| 通知管理 | `sys:notice:add`, `sys:notice:edit`, `sys:notice:delete`, `sys:notice:publish`, `sys:notice:revoke` |
| システム設定 | `sys:config:add`, `sys:config:update`, `sys:config:delete`, `sys:config:refresh` |

### 12.2 多言語対応（i18n）

すべてのシステム管理画面は多言語対応しており、以下の言語をサポート:
- 日本語 (ja)
- 英語 (en)
- 中国語簡体字 (zh-CN)

翻訳キーは `system.xxx.yyy` 形式で定義。

### 12.3 レスポンシブ対応

| デバイス | 対応 |
|----------|------|
| デスクトップ (1200px以上) | フル機能 |
| タブレット (768px〜1199px) | テーブル幅調整、Drawer幅90% |
| モバイル (767px以下) | 縦スタック、テーブル横スクロール |
