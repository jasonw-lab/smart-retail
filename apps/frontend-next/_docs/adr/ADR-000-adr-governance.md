# ADR-000: ADRライフサイクル運用

## ステータス

Accepted (2026-07-10)

## 背景

ADR-001〜ADR-008 は実装済みである一方、文書上のステータスが「承認待ち」「検討中」のまま残っていた。ADRを意思決定記録として扱うため、状態遷移と改訂履歴の運用を定義する。

## 決定

ADRのステータスは以下に統一する。

| ステータス | 意味                         |
| ---------- | ---------------------------- |
| Proposed   | 提案中。実装前または承認前   |
| Accepted   | 採用済み。実装方針として有効 |
| Superseded | 後続ADRに置き換え済み        |
| Deprecated | 非推奨。互換目的で残す       |

実装済みのADRは `Accepted (YYYY-MM-DD)` に更新する。改訂時は末尾に「変更履歴」を追加し、何をなぜ変えたかを記録する。

## 影響

- 新規ADRは `Proposed` から開始し、実装着手前に `Accepted` へ更新する。
- ADRを置き換える場合は旧ADRを `Superseded` にし、後続ADR番号を明記する。
- 実装レビューでADRとの差分が見つかった場合は、コードだけでなくADRも同じ変更で更新する。
